# Journalisering af project enlig forsøger

## Intro

This robot is responsible for journalizing responses of the OS2Forms form
for single parents.

The responses are emails found in a specific folder and journalized to the cpr number present in the
email body in KMD Nova.

After journalizing the mail is moved to another email folder.

The form is only active the first few months of the year but about 3000 responses are submitted.
